Overview This is the v0.18.4.3 release of the Monero GUI software. This is a highly recommended release that enhances protection against spy nodes when using a local node. The latest CLI release notes can be found on the precedent blog post Some highlights of this release are: Add support for Ledger Flex (# 4494 ) Update Qt to 5.15.17 (# 4498 ) Update P2Pool to v4.11 (# 4505 ) Minor bug fixes The complete list of changes is available on GitHub , along with the source code .
