Overview This is the v0.18.4.6 release of the Monero software. This release contains bug fixes. Some highlights of this release are: Daemon: fix bug in peer list filter (# 10317 ) Daemon: p2p connection bug fixes (# 10298 ) Multisig: fix key exchange failure in monero-gen-trusted-multisig (# 10284 ) Minor bug fixes and improvements The complete list of changes is available on GitHub , along with the source code .
