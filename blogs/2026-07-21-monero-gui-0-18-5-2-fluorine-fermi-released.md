Overview This is the v0.18.5.2 release of the Monero GUI software. This release fixes wallet generation during first use. The latest CLI release notes can be found on the precedent blog post Some highlights of this release are: Fix wallet generation during first use ( #4657 ) Warn when adjusting KDF rounds ( #4641 ) Fix precision loss when generating payment requests with large amounts ( #4649 ) Create wallets in memory in wizard ( #4654 ) Minor bug fixes The complete list of changes is available on GitHub , along with the source code .
